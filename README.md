# Stock Market Analytics Zoomcamp 2026 — meus estudos

Repositório pessoal com códigos, notas e homeworks do curso **Stock Market Analytics Zoomcamp**, da [DataTalks.Club](https://datatalks.club/).

## Links do curso

- Vídeo de apresentação: https://www.youtube.com/watch?v=Qph4w_WYECc
- Canal do YouTube (aulas): https://www.youtube.com/@DataTalksClub
- Repositório oficial do curso: https://github.com/DataTalksClub/stock-markets-analytics-zoomcamp
- Curso completo (PythonInvest): https://pythoninvest.com/course
- Página da cohort 2026 (prazos, calendário): https://courses.datatalks.club/sma-zoomcamp-2026/

## Estrutura

| Pasta | Módulo |
|---|---|
| `01-intro-and-data-sources/` | Introdução e Fontes de Dados |
| `02-dataframe-analysis/` | Trabalhando com Dados (Pandas) |
| `03-modeling/` | Modelagem Analítica (regressão, classificação, séries temporais) |
| `04-trading-strategy-and-simulation/` | Estratégia de Trading e Simulação |
| `05-deployment-and-automation/` | Deployment e Automação |
| `project/` | Projeto final |
| `notes/` | Anotações pessoais, resumos das aulas |

Cada pasta de módulo tem seu próprio `README.md` com o homework correspondente e o prazo de entrega. Ver `cronograma.md` para a visão geral de todos os prazos.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # no Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Como uso este repo

- Assisto as aulas no YouTube (canal do DataTalksClub).
- Escrevo/edito os notebooks e scripts aqui no VSCode.
- Consulto o [repositório oficial](https://github.com/DataTalksClub/stock-markets-analytics-zoomcamp) para material de apoio e enunciados de homework.
- Acompanho as tarefas e prazos na minha TODO list do Notion.
